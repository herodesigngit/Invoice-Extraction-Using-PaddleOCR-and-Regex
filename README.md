# 🧾 Invoice Extraction Using PaddleOCR and Regex

This project automates the extraction of key invoice fields such as **vendor name**, **invoice number**, **invoice date**, and **total amount** from scanned invoice images or PDFs. It leverages [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) for Optical Character Recognition and **regular expressions (Regex)** for parsing structured text data.

---

## 🚀 Features

- 📄 Extracts text from invoice images or PDFs using PaddleOCR  
- 🔍 Uses customizable Regex patterns to extract structured data  
- 🧠 Handles multilingual invoices (supports English by default)  
- 📦 Easy to integrate into existing accounting or ERP systems  
- ⚙️ Lightweight, fast, and open-source

---

## 🧰 Tech Stack

- **Python 3.8+**
- **PaddleOCR**
- **OpenCV**
- **Regex**
- **NumPy**
